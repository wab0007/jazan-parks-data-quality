# مشروع تحسين جودة بيانات الحدائق العامة — أمانة منطقة جازان

> **تنويه:** مشروع تدريبي مستقل باستخدام **بيانات افتراضية مصطنعة بالكامل**. لا يمثل سجلات أمانة منطقة جازان الفعلية، ولا تُستخدم إحداثياته لاتخاذ قرارات تشغيلية.

## 1. نبذة المشروع
دراسة تطبيقية لإظهار كيفية قياس جودة بيانات أصول الحدائق العامة، وتشخيص المشكلات وتوثيق إجراءات معالجتها ثم إعادة القياس. أُعد ضمن **الدورة التدريبية «إدارة جودة البيانات»** مع الإشارة إلى [أكاديمية سدايا](https://github.com/SDAIAAcademy) بوصفها جهة البرنامج في سياق المهمة التدريبية، دون الادعاء بأن الأكاديمية راجعت المشروع أو اعتمدته.

## 2. مشكلة الدراسة
يمكن أن تحتوي بيانات الحدائق في أي سجل أصول على حقول مفقودة أو معرفات مكررة أو مساحات غير صالحة أو إحداثيات خارج نطاق الدراسة أو رموز مرجعية غير متسقة أو سجلات قديمة. هذه المشكلات قد تقلل كفاءة التقارير والتحليلات.

## 3. هدف المشروع
- بناء مجموعة تدريبية من **48** سجلًا افتراضيًا.
- فحص **6** أبعاد للجودة على مستوى كل سجل (**288** اختبارًا).
- توثيق **25** عملية تصحيح تجريبية في سجل واضح.
- مقارنة المؤشرات قبل المعالجة وبعدها في لوحة مؤشرات قابلة للتحديث.
- تقديم تصور لحوكمة الضوابط واستدامة التحسين.

## 4. نطاق البيانات
الحقول الأساسية: معرف الحديقة، اسمها، البلدية، الحي، المساحة بالمتر المربع، خط العرض، خط الطول، النوع، حالة التشغيل، تاريخ آخر تحديث، ورمز البلدية.

## 5. قواعد الجودة
| البعد | قاعدة الفحص |
|---|---|
| الاكتمال | تعبئة 10 حقول إلزامية دون قيم فارغة أو مسافات فقط |
| التفرد | ظهور معرف الحديقة مرة واحدة فقط |
| صلاحية المساحة | المساحة رقم أكبر من الصفر |
| صحة الإحداثيات | خط عرض بين 16 و19، وخط طول بين 41 و44؛ نطاق مبسط للتدريب |
| الاتساق المرجعي | مطابقة اسم البلدية لرمزها، وصحة النوع والحالة وفق القوائم المعتمدة |
| حداثة البيانات | تاريخ آخر تحديث بين 2025-11-17 و2026-11-17 |

**طريقة القياس:** نسبة اجتياز الضابط = (عدد السجلات المجتازة ÷ 48) × 100. المؤشر المركب = المتوسط الحسابي لأبعاد الجودة الستة، بأوزان متساوية. **الدقة الميدانية الفعلية غير قابلة للقياس من البيانات المصطنعة**؛ التحقق منها يتطلب سندًا موثوقًا أو زيارة ميدانية.

## 7. محتويات المستودع
- `مشروع_جودة_بيانات_الحدائق_جازان.xlsx`: لوحة المؤشرات، مجموعتا البيانات، سجل المعالجة، القيم المرجعية، المنهجية، وخطة الاستدامة.
- `البيانات_قبل_التحسين.csv`: البيانات الأولية مع أخطاء مصطنعة.
- `البيانات_بعد_التحسين.csv`: البيانات المصححة.
- `سجل_المعالجات.csv`: تفاصيل الاختلافات والقرارات.
- `التحقق_من_جودة_البيانات.py`: برنامج Python قياسي لفحص قواعد الجودة وإخراج تقرير.
- `التوثيق_الفني.md`: قواعد العمل والمعالجة وحدود الدراسة.
- `دليل_العرض_والتسليم.md`: تسلسل عرض المشروع وخطوات رفعه إلى GitHub.
- `.gitignore`: استبعاد ملفات النظام المؤقتة.

## 8. تشغيل المشروع
**الخيار الأول — Excel (الأبسط):** افتح ملف `.xlsx` ثم ادخل إلى ورقة «لوحة المؤشرات» لقراءة المقارنة. تتضمن ورقتا قبل/بعد معادلات فحص تفصيلية لكل سجل.

**الخيار الثاني — Python 3.9 أو أحدث (دون مكتبات خارجية):**
```bash
python "التحقق_من_جودة_البيانات.py"
```
يقرأ البرنامج ملفي CSV في نفس المجلد، ويطبع نتائج المقارنة ويُنشئ ملف `تقرير_التحقق.json`.

## 9. منهجية التنفيذ
1. تحديد أهداف الجودة وتعريف قاموس البيانات.
2. إدخال أخطاء مقصودة لمحاكاة تدني جودة السجل.
3. تشغيل قواعد قياس الاكتمال والتفرد والصلاحية والاتساق والحداثة.
4. تحليل أسباب المشكلات والرجوع إلى **مراجع تصحيح افتراضية**.
5. تسجيل القرارات، وإنتاج نسخة مصححة.
6. إعادة الفحص واحتساب الفروق بين مؤشرات الجودة.
7. اقتراح ضوابط وقائية: التحقق عند الإدخال، ومنع التكرار، وربط القيم المرجعية، والمراجعة الدورية.
